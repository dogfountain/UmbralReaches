# Pillars

Umbral Reaches is a short, dark, solo action game about carrying light into a valley the sky is draining.

1. **The dark is the clock.** Gloom rises away from light; everything else in the night is measured against it. If a system makes the player forget the dark, it does not ship.
2. **Warmth is earned.** Light on screen is light the player made or reached: a brazier kindled, a fire lit, a bell rung. Nothing glows for free.
3. **The world teaches.** A mechanic that needs a sentence of UI text is wrong. Show it in the place, the person, the enemy; fix the design before adding the tooltip.
4. **Small and finished beats big and promised.** A thirty-minute slice that is whole is worth more than a night that is wide and half-built.

## Not this game

- An MMO treadmill (daily chores, gear grind for its own sake, borrowed MMO scaffolding).
- A survival-crafter (hunger, durability, base-building).
- An open world (a map to clear; the Realm is a path through one night, not a checklist).

## Kept by decision

Item level, gear sets and rested XP stay, by Luke's decision of 5 November. Fit them to the pillars. See `docs/DECISIONS.md`.

## How to use this

Before adding anything, ask which pillar it serves. If the answer is none, or only "more", leave it out.
